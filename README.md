# اتوگالری کیان — Kian Auto Gallery

سایت نمایشگاه خودرو، ساخته‌شده با Next.js. بدون بک‌اند و بدون دیتابیس؛
تمام اطلاعات خودروها و متن‌های سایت داخل خود پروژه (فایل‌های کد) نگه‌داری
می‌شوند. سایت به‌صورت کامل ریسپانسیو است و به دو زبان فارسی (پیش‌فرض) و
انگلیسی در دسترس است.

## تکنولوژی‌های استفاده‌شده

| بخش | ابزار | چرا |
|---|---|---|
| فریم‌ورک | Next.js 16 (App Router) | تولید صفحات به‌صورت استاتیک (SSG)، سریع و مناسب SEO |
| زبان | TypeScript | جلوگیری از خطاهای رایج در زمان توسعه |
| استایل | Tailwind CSS v4 | پیاده‌سازی سریع طراحی ریسپانسیو |
| چندزبانه‌سازی | next-intl | استاندارد و پرکاربردترین کتابخانه i18n برای Next.js App Router |
| منوی موبایل / گالری تمام‌صفحه | Radix UI (`@radix-ui/react-dialog`) | کتابخانه‌ی هدلس و در دسترس (accessible) که Vercel/shadcn هم از آن استفاده می‌کنند؛ مشکل ریسپانسیو یا صفحه‌کلید ندارد |
| آیکون‌ها | lucide-react | سبک و پرکاربرد در پروژه‌های Next.js |
| فونت | Vazirmatn (فارسی/لاتین) + JetBrains Mono (اعداد و مشخصات فنی) | از طریق `@fontsource` بارگذاری می‌شود، بدون نیاز به اینترنت گوگل‌فونت‌ها در زمان build |

## راه‌اندازی روی سیستم شما

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید. نسخه‌ی فارسی روی `/` و نسخه‌ی
انگلیسی روی `/en` در دسترس است.

برای گرفتن نسخه‌ی نهایی (production build):

```bash
npm run build
npm run start
```

> اگر می‌خواهید سایت را به‌صورت کاملاً استاتیک (بدون نیاز به سرور Node.js،
> مثلاً برای هاست‌های ساده یا GitHub Pages) خروجی بگیرید، در `next.config.ts`
> مقدار `output: 'export'` را اضافه کنید. توجه داشته باشید در این حالت
> بهینه‌سازی خودکار تصاویر next/image غیرفعال می‌شود.

## ساختار پروژه (مهم‌ترین بخش‌ها)

```
src/
├── app/[locale]/            صفحات سایت (Landing, automobiles, about, ...)
│   ├── page.tsx                    صفحه اصلی
│   ├── automobiles/page.tsx        فهرست کامل خودروها
│   ├── automobiles/[slug]/page.tsx جزئیات یک خودرو
│   └── about/page.tsx              درباره ما
├── components/              کامپوننت‌های مشترک (هدر، فوتر، کارت خودرو، گالری عکس، ...)
├── data/automobiles.ts      ⭐️ لیست خودروها — همین‌جا اضافه/ویرایش/حذف کنید
├── messages/
│   ├── fa.json               ⭐️ تمام متن‌های فارسی سایت
│   └── en.json               ⭐️ تمام متن‌های انگلیسی سایت
└── i18n/                     تنظیمات فنی چندزبانه‌سازی (نیازی به تغییر نیست)

public/images/automobiles/    ⭐️ عکس‌های خودروها (الان جای‌گیرنده/placeholder هستند)
```
