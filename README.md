# اتوگالری کیان — Kian Auto Gallery

سایت نمایشگاه خودرو، ساخته‌شده با Next.js. بدون بک‌اند و بدون دیتابیس؛
تمام اطلاعات خودروها و متن‌های سایت داخل خود پروژه (فایل‌های کد) نگه‌داری
می‌شوند. سایت به‌صورت کامل ریسپانسیو است و به دو زبان فارسی (پیش‌فرض) و
انگلیسی در دسترس است.

## تکنولوژی‌های استفاده‌شده

| بخش | ابزار | چرا |
|---|---|---|
| فریم‌ورک | Next.js 16 (App Router) | تولید صفحات به‌صورت استاتیک (SSG)، سریع و مناسب SEO |
| زبان | TypeScript | جلوگیری از خطاهای رایج در زمان توسعه |
| استایل | Tailwind CSS v4 | پیاده‌سازی سریع طراحی ریسپانسیو |
| چندزبانه‌سازی | next-intl | استاندارد و پرکاربردترین کتابخانه i18n برای Next.js App Router |
| منوی موبایل / گالری تمام‌صفحه | Radix UI (`@radix-ui/react-dialog`) | کتابخانه‌ی هدلس و در دسترس (accessible) که Vercel/shadcn هم از آن استفاده می‌کنند؛ مشکل ریسپانسیو یا صفحه‌کلید ندارد |
| آیکون‌ها | lucide-react | سبک و پرکاربرد در پروژه‌های Next.js |
| فونت | Vazirmatn (فارسی/لاتین) + JetBrains Mono (اعداد و مشخصات فنی) | از طریق `@fontsource` بارگذاری می‌شود، بدون نیاز به اینترنت گوگل‌فونت‌ها در زمان build |

## راه‌اندازی روی سیستم شما

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید. نسخه‌ی فارسی روی `/` و نسخه‌ی
انگلیسی روی `/en` در دسترس است.

برای گرفتن نسخه‌ی نهایی (production build):

```bash
npm run build
npm run start
```

> اگر می‌خواهید سایت را به‌صورت کاملاً استاتیک (بدون نیاز به سرور Node.js،
> مثلاً برای هاست‌های ساده یا GitHub Pages) خروجی بگیرید، در `next.config.ts`
> مقدار `output: 'export'` را اضافه کنید. توجه داشته باشید در این حالت
> بهینه‌سازی خودکار تصاویر next/image غیرفعال می‌شود.

## ساختار پروژه (مهم‌ترین بخش‌ها)

```
src/
├── app/[locale]/            صفحات سایت (Landing, automobiles, about, ...)
│   ├── page.tsx                    صفحه اصلی
│   ├── automobiles/page.tsx        فهرست کامل خودروها
│   ├── automobiles/[slug]/page.tsx جزئیات یک خودرو
│   └── about/page.tsx              درباره ما
├── components/              کامپوننت‌های مشترک (هدر، فوتر، کارت خودرو، گالری عکس، ...)
├── data/automobiles.ts      ⭐️ لیست خودروها — همین‌جا اضافه/ویرایش/حذف کنید
├── messages/
│   ├── fa.json               ⭐️ تمام متن‌های فارسی سایت
│   └── en.json               ⭐️ تمام متن‌های انگلیسی سایت
└── i18n/                     تنظیمات فنی چندزبانه‌سازی (نیازی به تغییر نیست)

public/images/automobiles/    ⭐️ عکس‌های خودروها (الان جای‌گیرنده/placeholder هستند)
```

## افزودن یا ویرایش یک خودرو

فایل `src/data/automobiles.ts` را باز کنید. هر خودرو یک آبجکت با این شکل است:

```ts
{
  id: "9",
  slug: "my-new-car",              // در آدرس /automobiles/my-new-car استفاده می‌شود
  brand: "Toyota",
  model: "Camry",
  year: 2024,
  bodyType: "sedan",                // یکی از: sedan | suv | coupe
  price: 3_000_000_000,             // به تومان، فقط عدد
  mileageKm: 5000,
  transmission: { fa: "اتوماتیک", en: "Automatic" },
  fuelType: { fa: "بنزینی", en: "Gasoline" },
  engine: "2.5L I4",
  drivetrain: "FWD",
  color: { fa: "سفید", en: "White" },
  seats: 5,
  highlights: { fa: ["برچسب ۱", "برچسب ۲"], en: ["Tag 1", "Tag 2"] },
  description: { fa: "توضیح فارسی...", en: "English description..." },
  featured: false,                  // true = روی صفحه اصلی هم نمایش داده شود
  images: [
    "/images/automobiles/my-new-car/1.jpg",
    "/images/automobiles/my-new-car/2.jpg",
  ],
}
```

برای حذف یک خودرو، کافی‌ست آبجکت مربوطه را از آرایه `automobiles` پاک کنید.
نیازی به تغییر جای دیگری از کد نیست — صفحه فهرست، صفحه اصلی، صفحه جزئیات و
فیلترها همگی به‌صورت خودکار به‌روزرسانی می‌شوند.

## جایگزینی عکس‌های واقعی

عکس‌های فعلی، جای‌گیرنده (placeholder) هستند و باید با عکس واقعی جایگزین
شوند. راهنمای کامل در `public/images/automobiles/README.md` است؛ خلاصه‌اش:
هر خودرو یک پوشه به نام همان `slug` دارد و داخلش فایل‌های `1.jpg` تا `4.jpg`
— فقط همین فایل‌ها را با عکس خودتان (با همین نام‌ها) جایگزین کنید.

## ویرایش متن‌های سایت

تمام متن‌های ثابت سایت (منو، دکمه‌ها، متن صفحه‌ی «درباره ما»، اطلاعات تماس،
متن‌های صفحه اصلی و ...) داخل `messages/fa.json` و `messages/en.json` هستند.
اطلاعات تماس (آدرس، تلفن، ایمیل، ساعات کاری) داخل بخش `About.contact` همین
فایل‌هاست — حتماً قبل از انتشار سایت این مقادیر را با اطلاعات واقعی گالری
خودتان جایگزین کنید.

## تغییر رنگ‌بندی یا فونت

پالت رنگی و فونت‌ها در `src/app/globals.css` (بخش `@theme`) تعریف شده‌اند:

```css
--color-ink: #37322e;       /* پس‌زمینه اصلی و متن روی زمینه روشن */
--color-surface: #423c37;   /* پنل‌های روشن‌تر روی پس‌زمینه تیره */
--color-taupe: #524944;
--color-stone: #6c6a68;
--color-mist: #b3b2b0;
--color-paper: #f6f3ee;     /* متن روی زمینه تیره */
--color-rust: #b34b0c;      /* رنگ اصلی/برجسته سایت */
--color-rust-dark: #7c3306; /* حالت hover رنگ اصلی */
```

## نکات فنی

- داده‌ها کاملاً استاتیک هستند؛ همه‌ی صفحات (شامل صفحه‌ی هر خودرو) در زمان
  `next build` به‌صورت HTML استاتیک تولید می‌شوند (SSG) — یعنی سرعت بالا و
  بدون نیاز به دیتابیس یا API.
- شماره‌ها (قیمت، کارکرد، سال) همیشه با ارقام لاتین نمایش داده می‌شوند تا با
  فونت مونو (JetBrains Mono) هم‌خوانی داشته باشند؛ این یک تصمیم طراحی است، نه
  محدودیت — در صورت تمایل می‌توانید در `src/lib/format.ts` تغییرش دهید.
- مسیر فارسی بدون پیشوند است (`/automobiles`) و مسیر انگلیسی با پیشوند `/en`
  (`/en/automobiles`)؛ این تنظیم در `src/i18n/routing.ts` قابل تغییر است.
